Simple discrod auto-message sender

ID - place where you have to put id of discord group, etc.

Your text - place where you have to put your text.

Your token - place where you have to put your discord token. (WARNING DON'T GIVE THIS TOKEN TO ANYONE)

Your image - place where you have to put image in format: C:/somedirectory/image .

slider with min - timer that affects the time between your messages.

radio button image requied - if you wanna send image you have to tick this thing if don't you don't have to. (without this images won't be able to send)

End timer - ends working 

Under the End timer - starts working
